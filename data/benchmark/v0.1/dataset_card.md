# CrystalProbe v0.1 Draft Dataset Card

## Dataset Summary

This is a draft seed manifest for the CrystalProbe polymorph-pair benchmark. It exists to validate the schema and curation workflow.

It is not a verified scientific benchmark.

## Current Contents

- 5 draft polymorph-pair records.
- 5 anchor molecules: aspirin, paracetamol, glycine, carbamazepine, and urea.
- All records currently contain placeholders and ambiguous stability labels.

## Intended Use

- Testing schema validation.
- Testing curation readiness reports.
- Testing pairwise prediction and fingerprint pipelines.

## Out-of-Scope Use

- Scientific claims about MLIP accuracy.
- Model comparison.
- Calibration claims.
- Redistribution as a verified chemical dataset.

## Promotion Requirements

Each record must be backed by licensed CIF references and DOI-backed experimental stability evidence before promotion to `reviewed` or `verified`.
